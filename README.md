# LlankanaWasi
LlankanaWasi: El portal donde las palabras cobran vida.  Más que un rincón de lectura, somos una "casa de trabajo" dedicada a potenciar la comprensión lectora de las nuevas generaciones. Un espacio digital diseñado para adolescentes donde el análisis crítico y la identidad se encuentran para transformar la lectura en una herramienta de poder.
